# Contributing

Use Node.js 22.13+/24+ and Python 3 for reference-data generator tests. Install with
`npm ci`. Run `npm run check`, `npm test`, `npm run test:data`, `npm run build` and
`npm run test:package` before submitting changes. Coverage reports are generated by
`npm run test:coverage` and ignored by Git. CI runs the same checks on Linux and Windows.

Type-aware ESLint and strict TypeScript checks are required. Source files permit
600 meaningful lines, functions 100 meaningful lines and complexity 20. Source,
test and script folders permit 14 direct files. Group protocols into subfolders.
Shared interfaces belong in `types.ts` or `*.types.ts`; imports across source
folders use `@/`, neighboring imports use `./`. Prettier defines formatting.

For a new decoder, supply a documented source, license and revision, valid
fixtures, expected field meanings/units, malformed/truncated cases and boundary
checks. Use independent wire encoders or external corpus fixtures where practical.
Do not create tests that only copy the parser's assumptions. Update
[coverage](docs/coverage.md) when capabilities change.

Preserve original payloads, explicit units and unknown fields. Do not infer the
meaning of numeric DF columns from plausible values. Report incomplete decoding
as partial; unsupported patterns must remain available as raw text. Bound input,
decompression and iteration. Check application checksums before exposing decoded
measurements. Never execute downloaded research scripts or untrusted message data.

Add upstream license notices for reused code/data. Source descriptions are
evidence for implementation, not a grant to relicense material. Private captures
and experimental scripts belong in ignored `test-results/`; sanitize public
fixtures and include only the data necessary for a regression.

Release preparation should validate the packed tarball in a separate consumer,
check TypeScript imports and a browser bundle, and review the package file list.
CI does not publish packages. Package/repository names do not reserve npm names;
check availability again before the first publication.
